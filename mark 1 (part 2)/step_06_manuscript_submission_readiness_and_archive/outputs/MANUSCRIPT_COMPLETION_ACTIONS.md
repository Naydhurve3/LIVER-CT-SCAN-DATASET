# Manuscript Completion Actions

Complete these items without reopening or reusing the test split:

1. **Literature citations and reference list** — External scholarly review required; intentionally absent
2. **Authors and affiliations** — Owner input required
3. **Ethics or applicability statement** — Owner/institutional determination required
4. **Dataset license and terms statement** — Verify against authoritative LiTS terms
5. **Author contributions** — Owner input required
6. **Conflicts of interest** — Owner input required
7. **Funding statement** — Owner input required
8. **Code and data availability** — Repository/archive decision required
9. **Target venue selected** — Venue not specified
10. **Venue formatting applied** — Requires selected venue
11. **Reporting-guideline mapping** — Select applicable current guideline before submission

Any future model development must be a separately versioned study with a new untouched evaluation cohort.
